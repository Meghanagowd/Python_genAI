# 🐍 Day 9 – Python Modules & Random Utilities

## 📌 Overview
Focused on understanding **Python modules** and building small utility programs using the `random` and `datetime` modules.

---

## 🧠 Concepts Covered

- Creating custom modules
- Importing modules in different ways:
  - `import module`
  - `import module as alias`
  - `from module import function`
- Using built-in modules:
  - `datetime`
  - `random`

---

---

## 🔧 Implementation Highlights

### 1. Custom Module
- Created `utils.py` with reusable functions
- Imported and used in `main.py`

### 2. Random Number Generation
- Generated random integers using `random.randint()`

### 3. List Operations
- Shuffled lists using `random.shuffle()`
- Manual swapping for custom shuffle logic

### 4. OTP Generator
- Generated a 6-digit OTP using random numbers

### 5. Password Generator
- Created random passwords using:
  - Letters
  - Numbers
  - Symbols
- Combined and shuffled elements for randomness

### 6. Username Generator
- Generated usernames using name + random number

### 7. Date Handling
- Used `datetime` module to get current date

---

## 🧪 Sample Outputs

- Random Number → `57`
- OTP → `483920`
- Password → `a@3k9#b`
- Username → `meghana_4821`
- Today’s Date → `2026-05-02`

---

## 🚀 Key Learnings

- Modules help organize code and improve reusability  
- Different import methods provide flexibility  
- Randomization is useful in real-world applications like:
  - OTP systems  
  - Password generation  
  - Simulations  
- Writing modular code improves readability and scalability
